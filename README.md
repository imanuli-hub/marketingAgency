# marketingAgency

A multi-agent marketing agency. A main orchestrator agent coordinates a team of specialist agents, each with its own goal.

## Agents

| Agent | Job |
|---|---|
| Orchestrator | Main agent: routes work, sets priorities, keeps the agency running |
| Creative Director | Owns creative vision and approves concepts |
| Strategist | Builds campaign and content strategy |
| Trend Scout | Finds emerging trends worth acting on |
| Competitor Watch | Tracks competitor activity |
| Copywriter | Writes copy for posts, ads and pages |
| Designer | Produces visual assets |
| Video Editor | Produces and edits video content |
| Publisher | Schedules and publishes content |
| Community Manager | Handles comments, DMs and engagement |
| Ads Manager | Runs and optimizes paid campaigns |
| Analyst | Measures performance |
| Reporter | Turns results into client reports |
| Brand Guard | Checks everything against brand guidelines |
| Client Liaison | Communicates with clients |
| Onboarding | Brings new clients into the agency |
